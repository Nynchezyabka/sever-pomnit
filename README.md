# Север Помнит

Создаём сайт-приложение для мастера ручного массажа Александры: «Север помнит · Пространство ручного массажа и заботы».

Атмосфера:
Уютное убежище от холода и шума города. Тёплые северные травы, согревающие масла, приглушённый свет, акварельно-ботаническая эстетика (не пиксельная, а мягкая природная: хвоя, мох, янтарь, тёплое дерево). Подходит для уставших людей и клиентов с СДВГ (без перегруза, без стыда и нравоучений).

Главное позиционирование:
«Только чуткие живые руки». Отстройка от аппаратной косметологии и сетевых клиник: руки мастера чувствуют фасции, дыхание и порог боли. Право на тишину во время сеанса.

Ключевые разделы:
1. Главный экран: атмосфера тепла, кнопки «Записаться на сеанс» (ссылка в Telegram @Sashsa_S) и «Подарить сертификат».
2. Манифест: «Почему только руки?» — просто и с уважением к телу.
3. Меню заботы: оздоровительный ручной массаж, лимфодренаж, сезонные ритуалы с северными травами, абонементы.
4. О мастере: Александра, график (Вт–Сб, 8:30–22:00, район ул. Полярная), канал t.me/massage_sever_pomnit.
5. ## Разработка и сборка

```sh
npm install
npm run dev
```

Сборка статического сайта с пререндерингом (SSG) для Yandex Cloud Object Storage:

```sh
VITE_SITE_URL=https://sever-pomnit.ru npm run build
```

Готовый сайт сохраняется в `dist/client`. Подробная инструкция по настройке бакета, HTTPS, домена и автодеплоя: [docs/yandex-cloud.md](docs/yandex-cloud.md). Настройка личного кабинета и базы клиентов в Supabase: [docs/supabase-layero.md](docs/supabase-layero.md) (разделы 1, 2, 4–7). Перенос базы Supabase на российский VPS (152-ФЗ): [docs/supabase-rf.md](docs/supabase-rf.md).
