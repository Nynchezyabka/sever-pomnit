# Бэкенд на Yandex Cloud Functions + YDB Serverless (без VPS, в РФ)

Личный кабинет (`/kabinet`), картотека мастера (`/kartoteka`), форма заявки (`#zapis`), подарки Зимнего сада и оповещения в Telegram работают полностью на серверах Yandex Cloud в России — без аренды VPS и без зарубежного Supabase.

---

## Что нужно создать в Yandex Cloud

1. **База данных YDB (Serverless)** — хранит аккаунты, профили, абонементы, визиты, заметки, заявки и подарки.
2. **Сервисный аккаунт** (например `backend-ydb`) с ролью `ydb.editor` — чтобы облачная функция могла читать и писать в YDB.
3. **Cloud Function** (Node.js 22) из папки `yandex-function/` — обрабатывает вход, регистрацию, заявки и отправляет уведомления в Telegram.

---

## Шаг 1. Создание базы данных YDB Serverless

1. Откройте **console.yandex.cloud** → выберите ваш каталог → **Managed Service for YDB → Создать базу данных**.
2. Тип базы: **Serverless**.
3. Имя: например `sever-pomnit-db`. Нажмите **Создать**.
4. Дождитесь статуса **Running** и сохраните со страницы обзора базы:
   - **Эндпоинт** (`YDB_ENDPOINT`), только адрес сервера без `/?database=...`: `grpcs://ydb.serverless.yandexcloud.net:2135`
   - **Размещение / База данных** (`YDB_DATABASE`), строка вида `/ru-central1/b1g.../etn...` *(это вторая часть из строки подключения)*
5. Слева откройте **Навигация → SQL-запрос**, вставьте целиком содержимое файла `yandex-function/schema.yql` и нажмите **Выполнить**.
   Должны создаться 7 таблиц: `users`, `profiles`, `subscriptions`, `visits`, `client_notes`, `booking_requests`, `gift_claims`.

---

## Шаг 2. Сервисный аккаунт для базы

1. Перейдите в **IAM → Сервисные аккаунты → Создать сервисный аккаунт**, назовите `backend-ydb`.
2. Выдайте ему роль **`ydb.editor`** на каталог (или на созданную базу YDB).

---

## Шаг 3. Создание Telegram-бота (для оповещений)

1. В Telegram откройте `@BotFather` → `/newbot` → задайте имя и скопируйте токен (`TG_BOT_TOKEN`).
2. Александра должна открыть нового бота и нажать **Start** (написать любое первое сообщение, иначе Telegram не разрешит боту ей писать).
3. Узнайте её `chat_id` через `@userinfobot` (`TG_CHAT_ID`).

---

## Шаг 4. Создание облачной функции (Cloud Functions)

1. Подготовьте ZIP-архив с кодом бэкенда (из корня репозитория):
   ```bash
   cd yandex-function
   zip ../yandex-function.zip index.js core.mjs ydb-store.mjs package.json package-lock.json
   ```
   *(Не включайте `node_modules` и `core.test.mjs`, и сжимайте именно эти 5 файлов внутри папки, а не саму папку `yandex-function` — `index.js` должен лежать в корне архива.)*

2. В консоли Yandex Cloud откройте **Cloud Functions → Создать функцию**:
   - Имя: `sever-pomnit-api`.
3. В редакторе функции выберите:
   - **Среда выполнения:** `Node.js 22`
   - **Способ загрузки:** ZIP-архив → загрузите `yandex-function.zip`
   - **Точка входа:** `index.handler`
   - **Таймаут:** `10` секунд
   - **Сервисный аккаунт:** выберите `backend-ydb` (из Шага 2)
4. В разделе **Переменные окружения** добавьте:
   - `YDB_ENDPOINT` = `grpcs://ydb.serverless.yandexcloud.net:2135`
   - `YDB_DATABASE` = `/ru-central1/...` (из Шага 1)
   - `JWT_SECRET` = любая длинная случайная строка от 32 символов (например результат `openssl rand -hex 32`)
   - `MASTER_EMAILS` = почта Александры (та, с которой она зарегистрируется в `/kabinet`, например `sasha@example.com`). После регистрации она автоматически получит доступ в `/kartoteka`.
   - `TG_BOT_TOKEN` = токен бота от `@BotFather`
   - `TG_CHAT_ID` = числовой `chat_id` Александры
   - `ALLOWED_ORIGINS` = `https://sever-pomnit.ru` (или несколько через запятую, например `https://sever-pomnit.ru,https://www.sever-pomnit.ru`; если пока тестируете с временного домена — можно временно оставить `*`)
5. Нажмите **Создать версию**.
6. На вкладке **Обзор** функции включите переключатель **Публичная функция** (чтобы браузеры посетителей могли отправлять заявки и входить в кабинет) и скопируйте **Ссылку для вызова** вида:
   `https://functions.yandexcloud.net/d4e...`

---

## Шаг 5. Подключение функции к сайту

1. В настройках репозитория на GitHub откройте **Settings → Secrets and variables → Actions → Variables**.
2. Создайте переменную:
   - `VITE_API_URL` = скопированная ссылка функции (например `https://functions.yandexcloud.net/d4e...` без `/` в конце).
3. Перезапустите деплой сайта: вкладка **Actions → Deploy to Yandex Object Storage → Run workflow**.

---

## Шаг 6. Проверка

1. Откройте главную страницу сайта → блок `#zapis`: вместо заглушки с кнопками должна появиться форма заявки. Отправьте тестовую заявку — она сразу придёт в Telegram-бот Александре.
2. Откройте `/kabinet` → вкладка **«Я здесь впервые»** → зарегистрируйтесь с почтой, указанной в `MASTER_EMAILS`.
3. Сразу после входа на странице появится кнопка **«Открыть картотеку клиентов»** (`/kartoteka`), где видна тестовая заявка.
